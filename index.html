About

Built on trust,
powered by freedom.

DtwinsCentral Fork is an enhanced version of the Wick Editor, a free and open-source tool for creating multimedia. We add powerful animation features like skewing, shape tweening, and a symbol system—all while keeping the runtime secure and the experience simple.

No tracking, no analytics, no payments. Just a free tool for makers.

The toolkit

More control.
More motion.

⌁

Skew & transform

Give objects perspective and personality with independent X/Y skew controls that work across your timeline. Create dynamic 3D effects without leaving the editor.

◌

Shape tweening

Morph compatible vector shapes into one another for fluid, organic transitions. Perfect for expressive character work and magical transformations.

▦

Symbols & libraries

Build once, reuse everywhere. Create symbol masters, compose instances, and organize a library of assets to speed up your workflow.

⌘

Timeline & keyframes

Precise frame-by-frame control with an intuitive timeline. Animate anything: position, rotation, scale, skew, and more across unlimited frames.

✍

Vector drawing

Built-in drawing tools for creating paths and shapes. Export to standard formats or keep your work inside the project for easy editing.

✓

Secure by default

Untrusted projects and imports are validated. Scripts and assets are sandboxed. You can share your work safely knowing the runtime is secure.
