<h1>Wick Editor Enhanced - DtwinsCentral Fork</h1>

This is an enhanced fork of the Wick Editor with advanced animation capabilities including:
- **Skewing** - Distort shapes and objects with precise skew controls
- **Shape Tweening** - Smoothly morph between different shapes
- **Symbol System** - Create reusable symbols and components
- **Symbol Library** - Built-in library of pre-made symbols

The Wick Editor is a free and open-source tool for creating games, animations, and everything in-between. It's designed to be the most accessible tool for creating multimedia projects on the web.

<p align="center"><img width="100%" src=".github/images/editor.svg"></p>

## 🆕 New Features

### Skewing
Apply skew transformations to objects for dynamic perspective effects. Control X and Y skew independently with real-time preview.

### Shape Tweening
Create smooth morphing animations between different shapes. Perfect for fluid, organic transitions and creative visual effects.

### Symbol System
- Create reusable symbols from any object or group
- Store symbols in the project
- Drag-and-drop symbol instances onto the canvas
- Edit master symbols and update all instances automatically

### Symbol Library
- Browse and import pre-made symbols
- Organize symbols by category (UI, Effects, Characters, etc.)
- Create custom libraries
- Share symbols across projects

## Getting Started

### Requirements

You'll need to download the following:

- [npm](https://www.npmjs.com/get-npm)

### Installation

1) Clone this repository:

    ```bash
    git clone https://github.com/dtwinscentral/dtwinscentralfork/
    ```

2) Using the command line, change directories into the newly created `dtwinscentralfork` folder:

    ```bash
    cd dtwinscentralfork
    ```

3) Install all dependencies using this command:

    ```bash
    npm install
    ```

### Running the Editor

1) Run the editor with this command:

    ```bash
    npm start
    ```

2) Open a web browser and go to this URL:

    ```bash
    localhost:3000
    ```

Have fun hacking on Wick! 🎉
